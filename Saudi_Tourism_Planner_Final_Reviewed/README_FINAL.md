# Adaptive AI Tourism Planner for Saudi Arabia — Final Hardened Source

This source bundle preserves the existing React/Tailwind visual design while correcting the ML/data assumptions and the frontend/backend integration contract.

## Components

- `saudi-trip-planner-backend/` — FastAPI, contextual recommender, itinerary engine, city-demand forecast endpoint, deployed ML/context artifacts, tests.
- `saudi-trip-planner-frontend/` — existing React + TypeScript + Tailwind UI with corrected API wiring, travel-month seasonality input, accessibility propagation, transparent estimated-cost labels, and non-fabricated trending scores.
- `tests/` — frontend source-contract regression tests.

The standalone retraining notebook is delivered separately as `Saudi_Tourism_AI_ML_Production_Pipeline.ipynb`.

## Run backend

```bash
cd saudi-trip-planner-backend
python -m venv .venv
# activate the venv
pip install -r requirements.txt
uvicorn main:app --host 0.0.0.0 --port 8000
```

Swagger: `http://localhost:8000/docs`

```bash

```

```bash
npm ci
cp .env.example .env
npm run dev
```

Production build:

```bash
npm run build
```

Set `VITE_API_BASE` in `.env` to the backend URL.

## ML architecture

The final implementation makes a strict distinction between:

1. **Forecasting model:** Extra Trees regression for one-month-ahead **city-total** KAPSARC POS demand.
2. **Recommendation ranking:** interpretable hybrid contextual ranking using explicit interests, record quality, KAPSARC city-total demand context, KAPSARC national tourism-sector demand context, DataSaudi seasonality, and distance.

KAPSARC does not provide an observed city × sector cross in the supplied source table, so the system never represents the two independent cuts as if they were an observed city-sector value.

## Grounding rules

- No fabricated visitor/star rating.
- Venue prices are category-level estimates and are labeled `Est.`.
- Unknown accessibility is not accepted in strict accessibility mode.
- Unknown opening hours remain unknown.
- Route distance/time are estimates based on Haversine distance, a documented road factor, and transport-speed assumptions.
- Human relevance and satisfaction metrics are not invented.
